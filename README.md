# Autonomous Warehouse Robot Simulation

Autonomous warehouse robot simulation built with Python and Webots, featuring A* path planning, route optimization, obstacle avoidance, and robot movement control.

## Technologies
- Python
- Webots
- E-puck robot model
- A* path planning
- Route optimization
- Grid-based navigation

## My Contributions
- Implemented the A* path planning algorithm
- Developed robot movement and navigation logic
- Designed the Webots simulation environment
- Tested and debugged navigation behavior across different obstacle layouts

## How It Works
1. Delivery points and obstacles are defined in the warehouse environment.
2. The system determines the delivery order.
3. A* generates a collision-free path.
4. The movement controller converts the path into forward and turning commands.
5. The robot follows the route in Webots.

## Results
The robot successfully navigated the simulated warehouse environment, followed generated paths, and avoided obstacles across multiple test scenarios.
